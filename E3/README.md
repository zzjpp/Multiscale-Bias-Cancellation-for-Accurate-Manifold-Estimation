# E3 scientific implementation

Run from the repository root:

```bash
python run_paper.py --experiment E3 --backend cpu --output NEW
```

Use `--profile smoke` for a reduced actual end-to-end check, never for paper values. All input generation, evaluation and plotting are connected by the root entrypoint. Original solver modules are retained as version-specific libraries; their historical deployment/replay CLIs are not the supported public workflow. No historical fitted-output archive is required. See the root README for exact protocol, hardware, failure rules and limitations.

No external dataset is required. Observations are generated by the original geometry and seed code. E3 fixed query/reference coordinates are distributed under `E3/assets/`; they are experimental design inputs, not fitted outputs.
