# Provenance

The final combined manuscript PDF hash is in PAPER_REFERENCE.json. Original scientific bytes are retained in the per-experiment frozen sources, source bindings, input checksums and stored audit records. The new top-level source manifest binds this complete release; it is a distribution integrity contract, not a claim of historical execution or independent reproduction.

E1/weight_control shares archived scale-specific points. E4/correspondence contains the fresh CP comparison and exact shared-query assets. nonuniform/E1 retains its population audit and packets. nonuniform/E2 retains its historical producer manifest separately in data/. The public V3 producer contract changes README documentation only; all executables, numerical settings and frozen scientific members are byte-identical. Its authentication-free Linux scheduler is retained as source, with no active queue, lock, transport helper or credential.

Original large E2/E3 and nonuniform-E2 raw archives are held separately. Original E5 finite packets are missing. See DATA_AVAILABILITY.md.

Cleanup did not change any retained scientific input, raw packet or numerical table. Unselected standalone studies and earlier documentation are in a reversible local archive outside the public repository. Selected plotting interfaces use the final paper map, with original filenames retained.
