# Data availability

The release includes selected original E1/E2/E3 tables, unchanged population evidence, all shared Figure 2 point packets, ten P1 finite correspondence packets, P1 population diagnostics, nonuniform E1 production/refined packets, and the complete nonuniform E2 768-row summary with all failures. Default nonuniform-E2 figures select STSP as in S17/S18; other methods remain in the saved source table for provenance and are not silently discarded.

Original E4 clean/noise arrays and common h1 reference coordinates are included for actual CP reruns. They have exact original file checksums. Full old E2/E3 and nonuniform-E2 archives remain separately held locally; they are not fabricated or represented as downloadable data. Synthetic generation code is included.

The 60 historical E5 held-out finite packets are unavailable in the local artifact. Selected Figure 8 PNG/SVG exports and their hashes are retained; raw median/IQR verification is incomplete. E5 population Table 2 is independently checkable from the seven distributed per-query packets.

Saved-result replay does not recreate historical GPU runs, certify continuum supremum errors, or establish independent replication. Inputs are controlled geometric experiments, including the disclosed YY initialization and geometry-assisted common queries. Historical source paths in bound receipts are labels, not runtime dependencies or authentication data.
