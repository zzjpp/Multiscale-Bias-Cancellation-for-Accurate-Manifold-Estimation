# Data availability

The release includes selected original E1/E2/E3 tables, unchanged population evidence, all shared Figure 2 point packets, ten P1 finite correspondence packets, nonuniform E1 production/refined packets, and the complete nonuniform E2 768-row summary with all failures. Default nonuniform-E2 figures select STSP as in E.17/E.18; other methods remain in the saved source table for provenance and are not silently discarded.

Original E4 clean/noise arrays and common h1 reference coordinates are included for actual CP reruns. They have exact original file checksums. Full old E2/E3 and nonuniform-E2 archives remain separately held locally; they are not fabricated or represented as downloadable data. Synthetic generation code is included.

All 60 historical E5 held-out finite packets are now distributed in `E5/data/finite/packets`, together with original audits/configuration, migration/recovery receipts and new dual-metric tables. Every original packet hash matches. The 256 recorded query metrics per packet reaggregate to all 24 medians and 48 IQR boundary values in the selected Figure 8 SVG. The original plotting source and fresh-output redraw entrypoint are included. These are recorded query metrics and input digests, not all noisy observations/fitted coordinates; independent truth-distance recomputation is outside this audit. E5 population Table 2 remains checkable from the seven distributed per-query packets.

Saved-result replay does not recreate historical GPU runs, certify continuum supremum errors, or establish independent replication. Inputs are controlled geometric experiments, including the disclosed YY initialization and geometry-assisted common queries. Historical source paths in bound receipts are labels, not runtime dependencies or authentication data.
