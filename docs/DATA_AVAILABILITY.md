# Inputs and reference values

All observations are generated by the original deterministic geometry and RNG code. E3's registered query/reference coordinates are fixed design inputs and are distributed in `E3/assets/`. Every reverse reference set contains 262144 coordinates. No external download or internal server path is required.

`reference_values/` contains small optional historical tables for comparison. They are excluded from `RUN_SOURCE_MANIFEST.json`, and `run_paper.py` does not read them. Full original finite/population packets, E5's recovered 60 metric packets, old exports, input observation archives and execution logs remain in the author's private local archive, rather than being required GitHub downloads. The 60 E5 packets were recovered and checked in the previous revision; their omission from this source-focused revision is deliberate, not a new data loss.

New packets preserve successes, failures, coordinates/metrics, seed lineages, source identity and numerical diagnostics under the caller's output directory. No old audit boolean is reused as scientific permission for a new run. Reduced smoke outputs are explicitly labeled and must not be used as paper results.
