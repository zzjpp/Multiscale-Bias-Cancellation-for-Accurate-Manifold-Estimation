\paragraph{Scope of the continuous CP benchmark.}
In the finite-sample experiment, the target branch is constructed locally and implicitly from the empirical STSP operator. Given the common reference point $y_1$, weighted PCA of the $h_2$-scale empirical covariance supplies a tangent vector $T$ and a normal basis $B$. We evaluate
\[
z(s)=y_1+sT+Bu(s),\qquad
B^\top\widehat R_{h_2}\bigl(z(s)\bigr)=0,
\]
by solving the empirical residual equation at each scalar search point and checking the full residual. The search variable $s$ is displacement along the estimated ambient tangent, not the true curve parameter. Implicit differentiation gives
\[
u'(s)=-\bigl[B^\top D\widehat R_{h_2}(z(s))B\bigr]^{-1}
B^\top D\widehat R_{h_2}(z(s))T.
\]
The continuous search uses this derivative to refine stationary points of $\|z(s)-y_1\|^2$. It receives no true curve parameterization or true normal basis. However, the shared fine-scale reference queries retain the original geometry-assisted construction using true normal charts. We therefore describe this as an \emph{empirical local-chart continuous CP benchmark with geometry-assisted common reference queries}, rather than a completely data-driven end-to-end reconstruction. The search concerns a numerically checked local fitted sheet; it does not certify the global closest point over arbitrary additional empirical residual components.

The reported $25.562$~s is the median measured wall-clock time on the CPU backend for a batch of 32 queries over ten original sample parents. It includes the charged common setup/reference checks and this implementation's empirical PCA, implicit chart construction, residual solves, continuous search, normal multistart checks, and extrapolation combination. True-curve arclength/query-grid generation, input-file reading, truth projections and error evaluation, and output writing are excluded. The median CP correspondence stage alone is $24.615$~s. These measurements characterize the particular implementation and benchmark protocol; they are neither a universal complexity bound nor the measured cost of a fully data-driven end-to-end CP pipeline.
