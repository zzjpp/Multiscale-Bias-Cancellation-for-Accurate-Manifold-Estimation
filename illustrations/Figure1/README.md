# Figure 1 — final-paper normal correspondence schematic

The native TikZ figure is the exact source selected in arxiv_final.pdf, page 3. Compile normal_correspondence.tex with pdflatex -interaction=nonstopmode -halt-on-error inside this directory, or input figure_tikz.tex in a manuscript using amsmath, amssymb and TikZ with calc and shapes.geometric. No external image or shell escape is needed.

normal_correspondence.pdf is the selected vector export; normal_correspondence.png is its raster rendering. figure_caption.tex supplies the caption. Drawing parameters and asymptotic annotations are schematic, not numerical estimator results.
