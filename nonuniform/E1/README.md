# Nonuniform E1

Saved paper figures: `python nonuniform/E1/reproduce.py --output NEW`. Use a fresh directory. All densities are defined relative to surface measure: circle `(1+.5 cos(theta))/(2*pi)`, S2 `(1+.5*x1)/(4*pi)`, Clifford `(1+.5 cos(u))/(2*pi**2)`, S3 `(1+.5*x1)/(2*pi**2)`, and corrugated `(1+.5 cos(v))/64.93745842335076`. The original corrugated geometry and its Jacobian remain in the frozen sources.

For E1 use `run_population.py --help`; omitting `--smoke` evaluates the full original query grid for the selected geometry/noise/resolution. For E2 use `parent.py --help` (new GPU parent, original n-prefix and exact-input gates) and `aggregate.py --help` (all original outcomes retained). The E2 sampler rejects clean area-uniform proposals with acceptance `(1+.5*phase)/1.5` before adding Gaussian noise. Original PCG64DXSM lineage, batch size 65536, kernel, solver, tolerances and failure rules are preserved. Full historical E2 raw archives are not distributed. S17/S18 select STSP only; the complete summary retains all three methods.
