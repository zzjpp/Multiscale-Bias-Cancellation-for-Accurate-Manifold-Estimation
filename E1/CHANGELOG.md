# Changelog

## 1.0.0 - 2026-09-26

- Collected the final audited E1 population maximum errors for STSP, DR, and
  Yao--Yau into one path-independent data table.
- Added one entrypoint that regenerates six main/supplementary figures.
- Added exact dependency pins, data checksums, registered slope checks,
  end-to-end tests, and a GitHub Actions workflow.
- Preserved the complete prespecified scale grids and all formal successful
  cells; no parameter or fitting-window selection was performed.
- Unified the Yao--Yau main and supplementary figures with the STSP/DR visual
  specification: identical colors, typography, bar-line styling, slope boxes,
  legend placement, spacing, and tick formatting; removed hatching, black bar
  borders, and grey grid lines without changing any numerical result.
